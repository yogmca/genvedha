# Genvedha Guru - Quick Start Guide

## 🚀 Get Started in 30 Seconds

### Step 1: Open the Chatbot
Open [`public/genvedha-guru.html`](public/genvedha-guru.html:1) in your browser

### Step 2: Click "Start Creating"
Click the **🚀 Start Creating** button

### Step 3: Provide Information
Answer the bot's questions:

```
Bot: "What would you like to name your e-commerce business?"
You: AquaGarden

Bot: "What type of products will you be selling?"
You: aquatic plants

Bot: "What product categories would you like?"
You: Floating Plants, Stem Plants, Carpet Plants, Moss
```

### Step 4: Review & Approve
- Review the requirements summary
- Click **✅ Approve & Create App**

### Step 5: Done! 🎉
Your e-commerce app is generated and ready to use!

---

## 💡 Pro Tips

### All-in-One Message
Provide everything at once:
```
AquaGarden selling aquatic plants. Categories: Floating Plants, Stem Plants, Moss
```

### Natural Language (Works in Offline Mode!)
```
I want to create an online store called FreshMart for organic vegetables
```

### Quick Categories
Just list them with commas:
```
Electronics, Laptops, Phones, Tablets, Accessories
```

## 🔌 Offline Mode (Default)

The chatbot works **without any API key** using smart pattern matching!

**Current Mode:** Check the badge at the top of the chat
- 🔌 **Offline Mode** (Orange) - No API needed
- 🌐 **AI Mode** (Green) - Claude API enabled

---

## ⚙️ Enable AI Mode (Optional)

Want natural language AI? 

1. Open [`public/genvedha-guru-config.js`](public/genvedha-guru-config.js:11)
2. Change: `USE_CLAUDE_API: false` → `USE_CLAUDE_API: true`
3. Ensure Claude API key is configured on server
4. Refresh browser
