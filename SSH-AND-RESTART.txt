COMMON ISSUES
-------------
1. If PM2 shows "errored":
   pm2 delete genvedha-website
   pm2 start server.js --name genvedha-website
   pm2 save

2. If port 3000 is in use:
   sudo lsof -i :3000
   sudo kill -9 <PID>
   pm2 restart genvedha-website

3. Check logs for errors:
   pm2 logs genvedha-website --lines 50
